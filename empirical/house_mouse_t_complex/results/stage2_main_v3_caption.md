# Manuscript main v3 figure caption

The house-mouse t-complex combines structural-state mixture, local quartet
distortion, and a changed ASTRAL summary topology. (A) Two explicit
four-group ASTRAL cladograms for standard/noncarrier chromosomes and all
standard plus reconstructed pseudo-t haplotypes. ASTRAL inference is
unrooted; *M. spretus* is used only to orient the display. (B) Direct
250-kb mean support for the named biological topologies `q_species`,
`q_t_alt`, and `q_other` along chr17; these names are not synonymous with
ASTRAL q1/q2/q3 across different inferred focal splits. (C) Source-defined
phylogeny-based recombination classification directly imported from the
authors' archived per-window topology files. The y-axis is the fraction of
5-kb windows per 500-kb bin assigned to each class. This is not a direct
recombination-rate estimate in cM/Mb. (D) Quartet composition for homogeneous
and mixed standard/pseudo-t arrangement states. Adjacent 5-kb windows are
linked and are not independent biological loci.
