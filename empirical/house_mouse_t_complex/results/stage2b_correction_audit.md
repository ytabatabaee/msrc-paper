# Stage-2 correction audit

The old `stage2_astral_summary.tsv` used the first annotated internal branch
for every tree. That is invalid for multi-population trees because the first
branch depends on Newick child order and is not necessarily the focal split.

The reusable functions `annotated_split_records()` and
`annotation_for_split()` in `scripts/house_mouse_stage2_utils.py` now identify
the canonical unrooted bipartition first and extract the annotation attached
to that split. The corrected focal values are:

| treatment | target split | CU | localPP | q1 | q2 | q3 | q sum |
|---|---|---:|---:|---:|---:|---:|---:|
| T0_STANDARD | Q_SPECIES | 0.056283 | 0.999985 | 0.369910 | 0.343656 | 0.286434 | 1.000000 |
| T1_ALL_WINDOWS | Q_T_ALT | 0.049097 | 1.000000 | 0.365364 | 0.323323 | 0.311313 | 1.000000 |

The seven-population analysis now emits every annotated nontrivial split in
`stage2_population_split_table.tsv` and compares P0/P1 only on canonical
shared, gained, and lost splits. The compact summary marks those rows as
`population_split_table_required` instead of presenting an unrelated branch as
a focal four-group q triplet.

The corrected outputs were regenerated by:

```bash
python empirical/house_mouse_t_complex/scripts/02i_correct_astral_summary.py
python empirical/house_mouse_t_complex/scripts/02j_population_split_analysis.py
```

Unit tests cover split-specific extraction, q normalization, child-order
invariance, and canonical split comparison.
