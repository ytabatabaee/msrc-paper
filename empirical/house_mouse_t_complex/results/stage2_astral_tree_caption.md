# Four-group ASTRAL tree caption

Unrooted four-group ASTRAL summaries of the published 5-kb ML gene trees,
shown as cladograms with *M. spretus* used only to orient the display. The
standard-only analysis returns `Q_SPECIES`, whereas the analysis including
standard and reconstructed pseudo-t haplotypes returns `Q_T_ALT`. Focal edge
annotations report split-specific CU, localPP, and biologically named quartet
frequencies. `q_species`, `q_t_alt`, and `q_other` are named biological
topologies; they are not synonymous with ASTRAL q1/q2/q3 across different
inferred focal splits. ASTRAL inference itself is unrooted.
