# Four-group ASTRAL tree caption

Unrooted four-group ASTRAL summaries of the published 5-kb ML gene trees,
shown with *M. spretus* as a visual root for presentation. The standard-only
analysis returns `Q_SPECIES`, whereas the analysis including standard and
reconstructed pseudo-t haplotypes returns `Q_T_ALT`. Branches are drawn on a
common coalescent-unit scale; focal branch annotations report split-specific
CU, localPP, and quartet frequencies. The visual root does not alter the
underlying unrooted ASTRAL inference.
