# Manuscript main figure caption

The house-mouse t-complex combines local quartet distortion with a changed
species-tree summary when linked windows and both structural arrangements are
sampled. (A) Two explicit four-group ASTRAL cladograms for standard/noncarrier
chromosomes and for all standard plus reconstructed pseudo-t haplotypes;
ASTRAL inference is unrooted and *M. spretus* is used only for display
orientation. (B) Direct 250-kb mean quartet support for all tips along chr17;
the named q values refer to biological topologies rather than fixed ASTRAL
q1/q2/q3 identities. (C) The source-defined phylogeny-based
recombination-state track, shown for the three *M. musculus* subspecies. Its
y-axis is the fraction of 5-kb windows per 500-kb bin assigned to each class;
it is not a direct cM/Mb recombination-rate estimate. The archived authors'
topology classifications are used directly. (D) Quartet composition for
homogeneous and mixed arrangement states. The linked 5-kb windows are not
independent biological loci, so displayed ASTRAL support can be
pseudo-replicated.
