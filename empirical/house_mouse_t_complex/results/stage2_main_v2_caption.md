# Manuscript main figure caption

The house-mouse t-complex combines local quartet distortion with a changed
species-tree summary when linked windows and both structural arrangements are
sampled. (A) Four-group ASTRAL trees for standard/noncarrier chromosomes and
for all standard plus reconstructed pseudo-t haplotypes; *M. spretus* is a
visual root only. (B) Direct 250-kb mean quartet support for all tips along
chr17. (C) The published phylogeny-based recombination-state track, shown for
the three *M. musculus* subspecies. This is an inferred local-tree
classification, not a cM/Mb recombination-rate estimate. (D) Quartet
composition for homogeneous and mixed arrangement states. The linked 5-kb
windows are not independent biological loci, so the displayed ASTRAL support
can be pseudo-replicated.
