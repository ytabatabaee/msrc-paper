Figure. ASTRAL4 sensitivity of Atlantic cod population summary trees to linked inversion windows. ASTRAL4 was run on the published 250-kb local population-tree windows after freezing inversion coordinates, population arrangement states, and the 12-population collinear baseline topology. The all-window treatment used all 426 local trees, the outside-only treatment used the 245 windows fully outside all frozen inversion intervals, and the inside-only treatment used the 176 fully inside windows. Inferred population summary trees were compared with the frozen baseline using unrooted Robinson-Foulds distance and recovered baseline internal splits. The all-window tree recovered 1/9 baseline splits, the outside-only tree recovered 3/9, and the inside-only tree recovered 2/9. Downweighting retained all outside windows while allowing at most m inside windows per linkage group; with m=1, no deterministic replicate exactly recovered the frozen baseline. These analyses test sensitivity to treating adjacent linked inversion windows as separate input trees and are not a fitted MSRC model.
