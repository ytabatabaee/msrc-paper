As a post-freeze summary-tree sensitivity analysis, we quantified local quartet-support profiles and ran ASTER/ASTRAL4 on the same published 250-kb population-tree windows used for the Atlantic cod spatial tests. For each window, local support fractions q_arrangement, q_baseline, and q_third were computed from the predeclared informative quartets. These fractions summarize induced local quartet resolutions and are distinct from ASTRAL4 branch q1/q2/q3 annotations.

ASTRAL4 analyses used ASTER commit ddc3dc6b28b20cecfec18cede8c6247decc82b77. Population summary trees were inferred with `astral4 -R -u 2 -t 2`, and the frozen 12-population collinear baseline was separately scored for each treatment with `astral4 -C -u 2 -t 2`. Treatments comprised all 426 windows, the 245 fully outside windows, the 176 fully inside windows, per-linkage-group inside-only sets, and leave-one-inversion-out sets. Boundary-overlap windows were excluded from clean inside/outside treatments.

To test whether linked inversion windows had disproportionate influence on quartet-summary inference, we performed a downweighting analysis that kept all fully outside windows while subsampling at most m fully inside windows per linkage group, with m in {1, 2, 5, 10, 20, 40, all}. Finite-m treatments used 100 deterministic replicates with seed 20260929 + 1000*m + replicate_id. Inferred ASTRAL4 population summary trees were compared with the frozen baseline using unrooted Robinson-Foulds distance and the fraction of recovered baseline internal splits; fixed-baseline scoring parsed the ASTRAL4 `-u 2` fields q1, q2, q3, pp1, pp2, pp3, and localPP.
