# Fire ants chromosome 16 data

Data tree for the fire-ant chromosome-16 social-supergene empirical analysis.

- `raw/`: immutable external source files. Stage 0 stores only selected small upstream documentation and the author coordinate table.
- `metadata/`: source manifests, region definitions, group definitions, provenance records, and checksums.
- `intermediate/`: generated handoff products for later stages.
- `processed/`: canonical analysis-ready tables frozen for downstream stages.

Large sequencing files, whole-genome alignments, VCFs, BAMs, FASTQs, TWISST weight tables, Newick trees, local-tree tracks, and quartet-support outputs are outside Stage 0. Stage 0 records provenance, structural vocabulary, focal groups, and the predeclared quartet design only.
